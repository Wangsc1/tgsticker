# TG 表情导入 · iPhone Scripting

使用提供 `Archive.extractZip` 的 Scripting 版本（官方文档列在 3.2.1）。不是 Scriptable，也不需要 Apple「快捷指令」。

## 安装

下载项目 ZIP。若 Scripting 的导入入口支持选择本地 ZIP，直接选择它。若你的版本没有本地 ZIP 导入入口，先在「文件」App 解压项目 ZIP，在 Scripting 新建「TG 表情导入」，将 `index.tsx`、`intent.tsx`、`importer.ts`、`import-view.tsx` 和 `live_activity.tsx` 导入到同一项目（也可新建同名文件并粘贴代码）。不要把项目 ZIP 当作待导入的表情包分享。

1. 从 GitHub 新安装时，项目预设勾选 Text、URLs、Images、FileURLs，并默认开启「总是在 App 中运行」。脚本仍只导入通过分享传入的本地 ZIP。已有安装若保留旧设置，请在项目编辑器点标题，进入 Intent 设置，确认已勾选 FileURLs，并开启「总是在 App 中运行」，无需删除重装。
2. 更新后先在 Scripting 中直接运行一次；如果提示权限，允许文件系统访问与向「照片」添加图片。

## 使用

在 Nagram 或 Telegram 打开机器人发来的 ZIP 预览 → 系统分享 → Scripting → TG 表情导入。不需要先保存 ZIP；如果 ZIP 已在「文件」App，也可以从那里调用系统分享。1.0.11 由 Scripting 主 App 尝试启动实时活动，显示解压和实际处理张数。当前分享扩展缺少实时活动声明，测试时必须开启「总是在 App 中运行」。这版不会主动跳回 Nagram；首次真机验证建议等导入完成再切回。若实时活动没启动，导入和通知照常运行。开始和结束各尝试发送一次静音本地通知；导入结束时撤回本次的开始通知，只留下显示实际图片和 GIF 数量的结果通知。请在 iPhone 的「设置 → 通知 → Scripting」中允许通知并开启横幅；通知未显示不会阻止导入。请保持分享流程不被中断，先用小 ZIP 测试，并到「照片」检查导入结果、确认 GIF 可以播放，再试大包。

脚本仅处理 ZIP 内的 JPG、JPEG 和 GIF。GIF 按原文件路径交给「照片」，脚本不会做图片解码、压缩或转换。导入结果分别显示成功保存的图片和 GIF 数量，有失败时也会显示失败详情。多卷 ZIP 分别分享，每卷都可独立导入。重复导入不会自动去重。

归档上限：单个 ZIP 60 MB、最多 512 个条目，单条目解压最多 20 MB，总解压最多 100 MB，足够容纳机器人当前输出的一卷。脚本只清理自己创建的临时解压目录，不删除原 ZIP；不访问网络，不上传图片。
